## 原法から保持する構造

下表は 2002 年資料の Figure 1（本文 p.2、PDF p.4）を要約し、右列に本スキルの応用を記したもの。原法は教室での協同学習であり、AI 向け手順そのものを述べた資料ではない。

| 原法の段階 | 本スキルでの応用 |
| --- | --- |
| 1. 学習内容への導入 | 論文と研究課題の全体像を把握 |
| 2. 専門課題の配布 | 論理的ピースごとの読解課題を設定 |
| 3. 専門家グループでの学習 | 担当別の精読と根拠付きノート |
| 4. 専門内容のクイズ | 教える前に原文照合して訂正 |
| 5. 元のグループで相互教授 | 担当間で説明し、依存関係を統合 |
| 6. 共有内容のクイズ | 章をまたぐ理解を原文で検証 |
| 7. 全体復習 | 網羅性と研究の論理を再確認 |
| 8. 個人評価 | 最終説明担当が論文全体を説明・検証 |
| 9. 必要時の再指導 | 未習得・誤読箇所を再読して再確認 |

Figure 3（本文 p.5、PDF p.7）は、専門課題とクイズを対応させながら形式を変えること、すぐに訂正すること、誤情報を各チームで直すことを扱う。本文 p.6（PDF p.8）は、共有後の確認、個人評価と必要時の再指導を説明する。再指導は評価で不足が見つかったときの対応であり、成功時にも形式だけで反復するための段階ではない。

## 翻案の境界

科学論文の根拠対応表、数式・図表の検証、再確認用の別問、到達条件、ファイル形式、章別解説は、本スキルで追加した設計。原法の「専門家グループ」を少数の担当エージェントまたは単独の読解パスに置き換えるため、人間の教室での協同学習をそのまま再現するとは主張しない。

この設計が AI の理解や正確性を改善することについて、上記文献が実証しているとは書かない。多視点の分析も、原文を確認しなければ同じ誤りを共有し得る。到達度は確認できた出典・説明・訂正によって限定的に示す。
