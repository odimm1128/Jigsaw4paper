# Jigsaw4paper

**科学論文を分担精読・相互説明・理解検証・再読し、原論文の章順に詳しく解説する Codex スキル。**

`jigsaw-paper-explainer` は、協同学習法 **Jigsaw IV（Jigsaw 4）** を AI の論文読解へ応用します。各章の主張を数式・図表・本文の根拠と照合し、章同士のつながりを統合してから、日本語の解説と検証記録を作成します。

## 特徴

- **原論文の構成に沿った解説**：章・節の順序を保ち、背景、方法、結果、限界のつながりを説明します。
- **数式・図表を含む精読**：記号、仮定、導出、比較条件、図表から読み取れる範囲を扱います。
- **根拠を追跡できる説明**：主要な主張に節・ページ・式・図表の位置を対応付けます。
- **理解確認と訂正**：専門クイズ、統合クイズ、個別評価を原文と照合し、誤読した箇所を再読します。
- **実行環境に応じた分担**：複数エージェントが使える場合は独立した部分を並行精読し、単独の場合は同じ工程を順に進めます。
- **KaTeX 対応の数式記法**：Markdown のインライン数式は `$...$`、独立数式は `$$` ブロックで出力します。

既定の読者は、専門外の理工系大学院生を想定しています。言語、前提知識、対象章、詳しさは依頼時に変更できます。短い要約だけ、全文翻訳だけ、文献探索だけの用途は対象外です。

## 導入

スキルを利用できる Codex 環境が必要です。本リポジトリは指示と参照資料で構成されており、専用アプリや実行サーバーの起動は不要です。論文の取得・PDF の抽出や表示には、実行環境で利用可能なツールを使います。

### Codex にインストールを依頼する

`skill-installer` が利用できる環境では、次のように依頼します。

```text
$skill-installer https://github.com/odimm1128/Jigsaw4paper/tree/main/skills/jigsaw-paper-explainer のスキルをインストールしてください。
```

### 手動で配置する

このリポジトリをダウンロードまたは clone し、`skills/jigsaw-paper-explainer/` をフォルダーごと、利用環境のスキル読み込み先へコピーします。`SKILL.md` だけでなく、`references/` と `agents/` も含めてください。

現行の公式ドキュメントでは、個人用は `~/.agents/skills/`、リポジトリ用は `.agents/skills/` が案内されています。配置先や呼び出し方法の詳細は [OpenAI 公式スキルドキュメント](https://learn.chatgpt.com/docs/build-skills) を参照してください。既存環境で別の保存先を使用している場合は、その環境の設定に合わせます。

配置後、Codex で `$jigsaw-paper-explainer` を選択します。スキルが表示されない場合は Codex を再起動してください。

## 使い方

論文 PDF、本文、ローカルパス、URL、DOI を渡せます。以下の `<...>` は実際の対象に置き換えてください。

### 論文全体を解説する

```text
$jigsaw-paper-explainer <論文の URL または DOI>
この論文を精読・検証し、章ごとに日本語で詳しく解説してください。
```

### ローカル PDF を読む

```text
$jigsaw-paper-explainer ./papers/paper.pdf
主要な数式の導出と図表の読み方を含めて、全章を解説してください。
```

### 対象章と読者レベルを指定する

```text
$jigsaw-paper-explainer <論文の URL>
第3章を中心に、必要な前提と関連する結果まで読んで解説してください。
線形代数は理解していますが、この分野の専門用語は初出で説明してください。
```

既定では理解確認への回答は Codex が行い、ユーザーの回答待ちで進行を止めません。読者自身が問題に答える形式を希望する場合は「対話型の理解確認を交えて」と指定してください。

## 読解の流れ

| 段階 | 行うこと |
| --- | --- |
| 1. 導入 | 論文の版、構成、研究課題、取得・確認できた範囲を整理 |
| 2. 専門課題の配布 | 論理的な部分に分け、担当範囲と確認する問いを設定 |
| 3. 専門精読 | 原文を読み、根拠・条件・他章との関係を専門ノートに記録 |
| 4. 専門クイズ | 各部分の理解を原文と照合し、誤りを訂正 |
| 5. 相互説明と統合 | 担当外の内容を説明し直し、章をまたぐ依存関係を接続 |
| 6. 統合クイズ | 結論の根拠、仮定、適用範囲を確認 |
| 7. 全体レビュー | 担当漏れ、未読箇所、不一致を点検 |
| 8. 個別評価 | 最終説明担当が論文全体を説明し、原文で検証 |
| 9. 再読と解説 | 必要な箇所を再確認し、原論文の章順に解説を作成 |

「IV」は方式の名称であり、必ず4人・4章に分けるという意味ではありません。詳しい手順は [SKILL.md](skills/jigsaw-paper-explainer/SKILL.md) にあります。

## 出力

書き込み可能な作業場所では、原則として次の成果物を保存します。

```text
jigsaw-<論文識別子>/
├── explanation.md   # 読者向けの章別解説
└── verification.md  # 根拠対応・確認範囲・評価・訂正・未解決点
```

`explanation.md` は各章の役割、必要な前提、内容の詳しい説明、主要な数式・図表、解釈の範囲、前後の章とのつながりを扱います。`verification.md` には、何を確認できたか、どこを訂正したか、何が未確認かを残します。形式の詳細は [出力規則](skills/jigsaw-paper-explainer/references/output-format.md) を参照してください。

チャットのみを指定した場合や保存できない場合は、同等の内容を会話内に出力します。生成した `jigsaw-*/` フォルダーは本リポジトリの `.gitignore` で除外しています。

### 数式の表示

KaTeX 対応の Markdown ビューアーで描画できるよう、次の記法を使用します。

```markdown
各項 $x_i$ の平均は、

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i
$$

である。
```

複数行の導出には `aligned`、場合分けには `cases` などを使い、論文固有のマクロは対応する標準記法に展開します。実際の描画には閲覧側の数式対応が必要です。このスキル自体に KaTeX ランタイムは含まれません。

## 確認範囲と限界

要旨しか取得できなければ、要旨に基づく暫定解説として出力します。本文にない章・式・結果を補作せず、図の未確認や補足資料の不足も明示します。著者の主張、報告結果、Codex による補足推論を区別します。

複数エージェントの一致やクイズへの正答は、論文の正しさや完全な理解を保証しません。このスキルは、確認した根拠と訂正の記録を通じて説明を点検できるようにするものです。

## Jigsaw IV の出典

本スキルが参照する原法は、人間の教室における協同学習法です。

- Holliday, D. C. (2000). *The Development of Jigsaw IV in a Secondary Social Studies Classroom*. [ERIC ED447045](https://eric.ed.gov/?id=ED447045).
- Holliday, D. C. (2002). *Jigsaw IV: Using Student/Teacher Concerns To Improve Jigsaw III*. [ERIC ED465687](https://eric.ed.gov/?id=ED465687).

確認済みの一次資料は上記の2000年・2002年の報告です。科学論文の根拠対応、数式・図表の検証、章別解説は本スキルで追加した設計であり、これらの文献が AI に対する効果を実証したものではありません。詳細は [原法と出典](skills/jigsaw-paper-explainer/references/jigsaw-method.md) を参照してください。
